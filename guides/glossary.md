# 用語集

| 用語 | やさしい説明 |
|---|---|
| HTML | 文書の構造・意味を表すマークアップ |
| CSS | 文書の表示・レイアウトを指定する言語 |
| JavaScript | 主にブラウザでUIの処理を行うプログラミング言語 |
| PHP | サーバー側で要求を処理しHTML/JSON等を返す言語 |
| HTTP | 要求と応答を交換する通信の基本的な約束事 |
| URL | リソースの所在を表す識別文字列 |
| DOM | HTML文書をプログラムから扱う木構造 |
| API | プログラム間の操作・データの受け渡し窓口 |
| JSON | 文字列や数値・配列・オブジェクトを表現するデータ形式 |
| SQL | 関係データベースに問い合わせるための言語 |
| 主キー | テーブルの各行を識別するキー |
| 外部キー | 別テーブルとの参照関係を表す制約 |
| トランザクション | 複数の更新をひとまとまりにする処理 |
| 認証 | 誰であるかを確認すること |
| 認可 | その主体が何をしてよいかを判断すること |
| Cookie | ブラウザが保存し要求時に送る小さな情報 |
| セッション | ログイン状態などを保つサーバー側の仕組み |
| SQLインジェクション | 外部入力がSQLの構文に混ざり処理の意味を変えてしまう問題 |
| XSS | 未信頼文字列がブラウザでコードとして解釈される問題 |
| CSRF | 利用者の意図と異なる状態変更をブラウザに送らせる問題 |
| IDOR | オブジェクトの識別子だけでアクセスできてしまう認可の不備 |
| SSRF | サーバーに予期しない宛先へ要求させる問題 |
| CSP | ブラウザでのリソース読み込み等を制限する応答ポリシー |
| CORS | ブラウザの別オリジンの応答読取に関する仕組み |
| prepared statement | SQLの構文と値を分けて扱う問い合わせ方式 |
| 信頼境界 | 未検証のデータが処理・権限の領域をまたぐ位置 |

## Cookie乗っ取り編・追加用語

| 用語 | 意味 |
|---|---|
| セッションハイジャック | 正規利用者の有効な認証済み状態を別の主体が不正利用すること |
| Cookie Theft | Cookieを第三者が取得すること。すべてのCookieが認証に使われるわけではない |
| Bearerトークン | 有効な値を保持しているだけで利用できる認証・認可用資格情報 |
| セッション固定（Fixation） | 既知のセッションIDをログイン後も使わせるなどして不正利用すること |
| HttpOnly | JavaScript APIからのCookie取得を制限する属性 |
| Secure | Cookieの送信を原則HTTPSへ制限する属性 |
| SameSite | 別サイトからの要求にCookieを添付する条件を制限する属性 |
| __Host- | 対応ブラウザで Secure・Path=/・Domain指定なしを要求するCookie名接頭辞 |
| Partitioned / CHIPS | 埋込み元サイトなどの区画ごとにCookieの保存状態を分離する仕組み |
| Infostealer | 端末内から資格情報・ブラウザ情報などを狙う情報窃取型マルウェア |
| リプレイ（再利用） | 盗難した有効な資格情報を再提示して認証済みとして扱わせること |
| DBSC | Device Bound Session Credentials。端末内鍵を用いたセッション更新の保有証明を目指す仕組み |
| 偽陽性 / 偽陰性 | 異常でないのに異常と判定する／異常なのに見逃すこと |
| 失効（Revoke） | サーバー側でIDやトークンが今後受け入れられないようにする処置 |
