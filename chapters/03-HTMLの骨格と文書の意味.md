# 第03章：HTMLの骨格と文書の意味

> **読解教材（実行不要）** — 以下のコードは比較のための断片です。危険版を実行・公開しないでください。

**難易度：** 入門

## この章でできるようになる
<!doctype html>、head、body、見出し、段落、リンク、画像を適切に書ける。

## 全体像
HTMLは見た目の指示ではなく、情報に「これは見出し・本文・リンク」と意味を付与する言語。

## 🎙 読み上げ可能な講師ナレーション
HTMLのタグは文章の役割を決めます。大切なのは正しく閉じることだけでなく、見出しの階層を崩さないことです。クローラーや音声読み上げ機能もこの構造を使います。まずは装飾を減らし、意味の伝わる1ページを作りましょう。

## 1. 危険なコードを読む
未信頼の値がどこから来て、どの命令や判断へ渡るかに注目してください。

```html
<div onclick="location.href='/about'">会社概要</div>
<div class="headline">ようこそ</div>
```

## 2. 安全側のコードと比較する
これは設計上の考え方を伝える**抜粋**です。例外処理や周辺設定が省略されている場合があります。

```html
<!doctype html>
<html lang="ja">
<head><meta charset="utf-8"><title>会社概要</title></head>
<body>
  <main><h1>ようこそ</h1><a href="/about">会社概要</a></main>
</body>
</html>
```

## 3. 一行ずつ意味を説明する
1. <!doctype html>はブラウザに標準モードで解釈させる宣言。
2. lang="ja"は文書の主言語を示し、支援技術の読み上げにも関係する。
3. h1は主要見出し、a hrefは移動先を持つリンク。

## 4. 頭の中で処理の流れを追う
① HTMLは文書ツリーに変換→② 要素の意味を解釈→③ CSSで表示→④ 支援技術にも意味を伝達。

### 根本原因
キーボード操作や支援技術が要素の役割を理解しにくくなる。

### 修正の原理
リンクはa要素、見出しはh1要素。見た目だけでなく文書の意味が支援技術や検索エンジンへ伝わる。

### 防御を重ねるとしたら
移動はa、操作はbutton、文章構造はh1〜h6を使う。
