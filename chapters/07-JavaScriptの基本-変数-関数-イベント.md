# 第07章：JavaScriptの基本・変数・関数・イベント

> **読解教材（実行不要）** — 以下のコードは比較のための断片です。危険版を実行・公開しないでください。

**難易度：** 基礎

## この章でできるようになる
const/let、配列、オブジェクト、イベントリスナー、条件分岐を扱える。

## 全体像
JavaScriptは画面の動きや、サーバーとの通信を担当する。ブラウザのJSは秘密情報の保存場所ではない。

## 🎙 読み上げ可能な講師ナレーション
次に画面を動かしてみます。JavaScriptの変数には型があり、オブジェクトや配列を扱えます。イベントは「ユーザーがボタンを押した」などの合図です。画面への変更はDOM APIで行います。動作確認にはConsoleを使いましょう。

## 1. 危険なコードを読む
未信頼の値がどこから来て、どの命令や判断へ渡るかに注目してください。

```javascript
const ADMIN_PASSWORD = "secret123";
if (input === ADMIN_PASSWORD) showAdmin();
```

## 2. 安全側のコードと比較する
これは設計上の考え方を伝える**抜粋**です。例外処理や周辺設定が省略されている場合があります。

```javascript
const button = document.querySelector('#count');
let count = 0;
button.addEventListener('click', () => {
  count += 1;
  button.textContent = String(count);
});
// 認証・秘密値はJavaScriptに配置しない
```

## 3. 一行ずつ意味を説明する
1. constで要素への参照、letで更新するカウンターを定義する。
2. addEventListenerはクリックされたときの処理を登録する。
3. textContentはHTMLの実行解釈をさせず文字を更新する。

## 4. 頭の中で処理の流れを追う
① 変数を定義→② ボタンのクリック登録→③ イベント発火→④ DOMの文字列を更新。

### 根本原因
ブラウザに配信されるJSは全て利用者から読める。

### 修正の原理
JavaScriptは閲覧者がソースを読める。変数やイベントはブラウザ上で機能するが、認証や管理者権限の判断はサーバー側に置く。

### 防御を重ねるとしたら
秘密はサーバー側で管理し、ブラウザには必要最小限の情報だけ渡す。
